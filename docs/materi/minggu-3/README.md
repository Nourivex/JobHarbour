## 📑 Struktur Isi Lembar Kerja (Presisi 2 Halaman A4 Sesuai Modul Ajar)

Struktur tugas individu ini strictly mengikuti format Bab 32 Modul Ajar 03:

```text
32. Tugas Individu Minggu ke-3
32.1 REST API Design Worksheet
Buat rancangan awal REST API untuk project semester.
A. Bagian A - Identifikasi Resource (Minimal 5 resource)
B. Bagian B - Endpoint (Minimal 10 endpoint)
C. Bagian C - Response (Minimal 3 endpoint dengan status code, contoh JSON, kondisi error)
```

1. **Halaman 1:**
   - Kop resmi Universitas Harkat Negeri + Badge `Dosen Pengampu: Zaenul Arif, S.Kom., M.Kom`.
   - Judul resmi: `32. Tugas Individu Minggu ke-3: 32.1 REST API Design Worksheet`.
   - Tabel Identitas Mahasiswa (Nama, NIM, Semester, Mata Kuliah, Project Semester).
   - **Bagian A - Identifikasi Resource:** Tabel 5 resource (No, Resource, Deskripsi).
   - **Bagian B - Endpoint:** Tabel 10 endpoint (No, Method, Endpoint, Fungsi).
2. **Halaman 2:**
   - Kop resmi Universitas Harkat Negeri + Badge `Dosen Pengampu: Zaenul Arif, S.Kom., M.Kom`.
   - **Bagian C - Response:** 3 endpoint representatif lengkap dengan status code sukses, contoh response JSON, status code error, dan kondisi error.
