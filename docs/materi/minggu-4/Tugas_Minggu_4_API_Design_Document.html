Perhitungan skor matchmakingPOST /api/v1/applications

Transisi sebagai sub-resource		Setiap perpindahan tahap tercatat beserta waktu, pelaku, dan catatan, sehingga riwayat dapat dibaca kembali. Server memvalidasi state machine; transisi melompat, mundur, atau dari tahap final ditolak dengan 409.
